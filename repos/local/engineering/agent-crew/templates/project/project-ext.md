# 项目角色扩展片段（说明）

> 本目录是项目自有扩展区，由 init 首次生成说明文件，之后由项目维护；技能升级不覆盖。
> 角色基类在技能源 `{{skill_root}}/templates/agents/`；项目角色文件用 `extends: skill:<role>` 继承。

## 1. 用在哪里

- 路径：`docs/crew/project-ext/<role>.md`（目录可由配置 `paths.projectExt` 改）。
- 用途：同一角色在多个任务里重复使用的项目动作、本地命令、字段说明；由项目角色文件正文用相对指针引用。
- 不是 agent：不会被 runtime `agent list` 发现，不注册为角色，不参与 dispatch 继承组合。

## 2. 怎么写

- 只写项目增量：项目独有的检查项、数据源、命令与边界；不复制技能规则/验收正文。
- 一个 role 一个文件；标题用项目独有名称，避免与技能基类的 `## 引用`、`## 职责边界` 重名。
- 需要跨角色共享的片段放 `_common.md`，由各角色文件按指针引用。

## 3. 与继承的关系

- 角色 = 技能基类 + 项目角色文件正文（append-only，base 先、项目后）；扩展片段不参与组合。
- 基类升级只改技能源；项目角色文件与扩展片段无需改动。
- 组合报告出现受保护标题冲突或残留 token 时，dispatch 拒绝启动；先改项目标题或修指针。
