"你是 Excel 转 Word 专家，

批量文件处理..."
↓
→ system prompt + tools + middlewares 按此专家定制
项目绑定多专家时 ↓
ExpertSubagentProvider
其他绑定的专家 → 暴露为子代理（通过 task 工具委派）
allowed_subagent_types 白名单控制可委派范围
子代理配置同样从 config.yaml + SOUL.md 加载
核心要点：LangGraph 只注册了 lead_agent 一个图。专家身份完全靠 agent_name 在运行时从 DB → 磁盘文件 → make_lead_agent(config) 动态注入，区分的是 system prompt、工具集和中间件配置，而非图结构本身。
